# Aperture Lab for Raspberry Pi

A retro 1970s lab-style desktop for Raspberry Pi OS (Pi 5, 64-bit): Lab Desk widgets, custom taskbar and start menu, themed login and boot screens, sounds, Tailscale remote access and travel security.

Install or update (run as your normal user, not sudo):

    bash retro-lab-install.sh

After the first install, `retro-update` fetches the newest version from this repo.
